# 从零接上 QQ

目标：在群里 @ 它一句，它能回。中间只有四步，每一步都能单独验证。

先把两件事分清楚，后面所有困惑都来自把它们混在一起：

- **soapbot** 是"大脑"：收消息、调模型、发回复。它不认识 QQ 协议。
- **NapCat** 是"接口"：登录 QQ 号，把 QQ 的消息转成 soapbot 能懂的格式，再把回复送回去。

两者之间用一条本地 WebSocket 连接（默认 `ws://127.0.0.1:3001`）。**顺序是 NapCat 先登录成功，那条连接才会打开**——所以「3001 没监听」几乎总是"QQ 还没登录"，不是 soapbot 的问题。

---

## 第 1 步：起 soapbot

```bash
python -m soapbot.cli start      # → http://127.0.0.1:6185
```

打开面板第 07 页，填模型 Key，点「测试」变绿。这一步先做完，否则后面接上 QQ 也不会回话。

**怎么确认成功**：第 01 页「进程」是绿的。这时候「QQ 连接」还是灰的，正常。

---

## 第 2 步：起 NapCat

**Windows（常见）**：装好的 NapCat 用 `scripts/install_napcat_task.ps1` 注册成计划任务，然后启动它：

```powershell
powershell -ExecutionPolicy Bypass -File scripts\install_napcat_task.ps1 -QQNumber 你的QQ号 -Start
```

必须用计划任务，不要从远程桌面/远程 shell 里直接双击启动：那种进程会在会话断开两小时后被系统一起收走，表现就是"机器人莫名其妙掉了"。

**Docker（有 Docker 的机器）**：面板第 07 页的「协议端」卡片可以直接起官方镜像，不用敲命令。

**怎么确认成功**：NapCat 自己的 WebUI 在 `http://127.0.0.1:6099` 能打开。

---

## 第 3 步：扫码登录 QQ

打开 `http://127.0.0.1:6099`，用手机 QQ 扫码。

扫完之后：

- NapCat 日志里出现登录成功；
- **`3001` 开始监听**（这是最关键的一步，可以用 `netstat -ano | findstr 3001` 看）；
- 面板第 01 页的「QQ 连接」变成绿的，并且显示登录的 QQ 号。

如果二维码显示"已过期"或者一直不变：NapCat 在二维码超时后会停在那里，不会再自己出新码。重启 NapCat 就会出新的。这是 NapCat 的行为，不是面板在骗你——面板现在会写明这张码多久没变、上次失败原因是什么。

---

## 第 4 步：把连接信息交给 soapbot

面板第 07 页「协议端」卡片上有一个「写入连接」按钮：它会自动把 `ws://127.0.0.1:3001` 和账号写进 `adapters.yaml`，不用手抄。

写入后面板会提示需要重启，重启即可。

**怎么确认成功**：第 01 页「QQ 连接」绿、第 02 页「适配器健康」绿。

---

## 出问题按这个顺序查

**群里 @ 它没反应**

1. 第 01 页：进程绿不绿？QQ 连接绿不绿？
2. 第 02 页：适配器健康、模型健康，哪个红？
3. 第 09 页：随便找一条进来的消息，看它停在哪一步、为什么停。

三页看完基本就定位了，不用翻日志。

**「QQ 连接」一直灰，3001 没监听**

去 `http://127.0.0.1:6099` 看 QQ 是不是登录状态。九成是没登录或登录过期。重启 NapCat 重新扫码。

**NapCat 起来了，6099 也能开，但 3001 还是不监听**

NapCat 登录了但没开 OneBot 服务。在面板第 07 页点「写入连接」，它会补上这段配置，然后**重启 NapCat**——配置是启动时读的。

**每 72 小时准时掉一次**

Windows 计划任务的默认时限是 72 小时，到点会把 NapCat 连同 QQ 一起杀掉。用 `scripts/install_napcat_task.ps1` 注册的任务设的是"不限时"，不会再出现。如果你是自己手工建的任务，去任务计划程序里把「如果任务运行时间超过以下时间，停止任务」取消掉。

**面板能开，但二维码扫了没反应**

先看面板写的"这张码已刷新于多久之前"。超过两分钟基本就是过期了，点「换一张」；如果一直拿到同一张，重启 NapCat。

---

## 和"换服务器"有关的两句话

- 换机器时不要拷 `C:\soapboot.ps1`（那份脚本会打开 WinRM 明文认证和本地账户令牌策略，是为了远程部署临时用的）。
- 新机器先加"只允许你的 IP 访问 3389/5985"的规则，再删掉"允许所有人"的那条。顺序反了会把自己关在门外。
